# TinyTUI
Cross-platform .NET library written in C# that allows you to create simple terminal user interfaces.

Website: https://uwap.org/projects/tinytui

Changelog: https://uwap.org/changes/tinytui

Guides: https://uwap.org/guides/tinytui

## Main features
- Listing options
- Showing an input page with textboxes and selectors
- Showing messages
- Showing exceptions
- Manual outputting with shortcuts for colorful texts

## Installation
You can get the NuGet package here: [Useful.TinyTUI](https://www.nuget.org/packages/Useful.TinyTUI/)

You can also download the source code from GitHub and add a reference to it from your project.
